# AI 功能使用政策

## 概述

财芽（CaiYa）提供 AI 驱动的投资分析辅助功能。用户需使用自己的 API Key 调用大语言模型服务。

## 使用方式

### 客户端直连模式（默认）

- API Key 存储在您浏览器的 localStorage 中
- 前端代码直接向 OpenAI / Claude API 发起请求
- Key 不经过财芽服务器

### 安全提示

- 浏览器环境下 API Key 存在泄露风险，请勿在公用设备上保存 Key
- 建议使用支持限额管控的 API Key
- 定期轮换您的 API Key

## 重要声明

1. AI 生成内容仅为模型基于历史数据的统计推断，**不构成投资建议**
2. 大语言模型可能存在"幻觉"，生成看似合理但实际错误的信息
3. 用户应结合多方信息独立做出投资决策
4. Token 消耗由对应的 API 服务商按量计费，与财芽平台无关

## 使用规范

- 禁止使用 AI 功能生成荐股、诱导入市等内容
- 禁止将 AI 输出包装为投资建议发布在论坛
- 违反上述规范将限制 AI 功能使用权限
